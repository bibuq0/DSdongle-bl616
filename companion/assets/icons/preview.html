DS5 Dongle 图标方案选择

5 个候选方案（浏览器放大看细节），告诉我编号即可。选定后我会接入窗口图标与打包。

1. 手柄 + 蓝牙

DualSense 手柄轮廓 + 蓝牙符文，直观表达"无线手柄适配器"

2. 无线信号波

手柄 + 顶部无线信号弧线，强调无线连接

3. 字母 D

大写的 D + 绿色配对点，简洁有辨识度（DS5Dongle）

4. 双环链接

互锁双环 + 中心圆点，象征"连接/配对"

4v2. 双环链接（优化版）

渐变描边双环 + 前后交叉层次 + 中心发光核心 + 无线天线

4v3. 双环 + 信号

左右互锁双环 + 中心无线信号，三个元素极简版

4v4. 双环交叉 + 信号

上下交错互锁双环（蓝环压白环/白环压蓝环）+ 中心信号

4v5. 横放交叉 + 信号

左右横放双环 + 交叉处一上一下互锁 + 中心信号

4v6. 同心波纹

双环交叉不变，中心改为「圆点 + 同心波纹」（雷达/广播感）

4v7. 细线 wifi

双环交叉不变，中心改为纯白细线 wifi（更轻量）

4v8. 扁平粗 wifi

双环交叉不变，中心改为苹果式扁平粗线条 wifi

5. 极简徽章

极简手柄徽章 + 状态点，偏扁平工具风
